# Перенос обучения ResNet-18 для распознавания ретинобластомы по снимкам глазного дна при дефиците размеченных данных

Научная статья для курса «Научное письмо», 4-й курс прикладной математики.

- **Студент:** Бабенко Анастасия Сергеевна
- **Научный руководитель:** А. С. Кожаринов
- **Кафедра:** инженерной кибернетики, НИТУ «МИСиС»

## О чём работа

Цель — проверить, улучшает ли дополнительное обучение ResNet-18 на офтальмологических изображениях распознавание ретинобластомы при недостатке размеченных данных.

Планируется сравнить прямой перенос из ImageNet с промежуточным обучением на IDRiD, а также три функции потерь: кросс-энтропию, взвешенную кросс-энтропию и focal loss. Основная метрика — macro-F1; отдельно оценивается качество распознавания ретинобластомы. Разбиение данных предусматривает контроль пациентов и дубликатов.

**Статус:** подготовлены введение, анализ работ, постановка задачи и описание методов. Эксперимент запланирован; целевой датасет требует уточнения.

Поместите оба файла в одну папку и выполните:

```bash

```

В Overleaf загрузите оба файла, выберите компилятор **XeLaTeX** и главный файл `article.tex`.
